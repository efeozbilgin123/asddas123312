# Kahvehane

Arkadaşların buluşup takıldığı, tarayıcıda çalışan sıcak bir 3D sosyal mekân:
masalarda Okey, Batak, Pişti ve Bilardo; TV'de maç, Yeşilçam; müzik ve sohbet.

Tasarım: `docs/superpowers/specs/2026-11-15-kahvehane-sosyal-lobi-design.md`

## Çalıştırma

```bash
npm install
npm run fetch-assets   # Poly Haven modellerini/dokularını indirir
npm run dev
```

Testler: `npm test` · Üretim derlemesi: `npm run build`
