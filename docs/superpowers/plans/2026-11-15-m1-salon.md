# Kilometre Taşı 1 — Salon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Single-player, no-network version of the cozy salon: real downloaded models, warm realistic lighting, stove fire, snow outside the window, a cat that lives in the room, and one walking/sitting avatar. Shown to the owner on a live link for approval of the realistic look.

**Architecture:** Fresh npm-workspaces repo replacing the old tree. `client/` is Vite + TypeScript + Three.js. All behavior that can be pure (movement, collision, seat finding, cat brain, flicker, quality detection, layout validation) lives in small pure modules unit-tested with Vitest; Three.js modules only render pure state. Assets are fetched by a script from Poly Haven into `client/public/assets/` and described by one manifest.

**Tech Stack:** Node ≥ 20, TypeScript 5 (strict), Vite 6, three ^0.170, Vitest 2, Playwright (pre-installed; launch with `chromium.launch()`).

**Spec:** `docs/superpowers/specs/2026-11-15-kahvehane-sosyal-lobi-design.md` (§8.2 Mekân, §8.3 Avatarlar, §9 step 1, §4 anti-goals).

## Global Constraints

- All UI copy is Turkish.
- No code-generated box/cylinder furniture or props in the visible scene (spec §4). The room shell (floor, walls, ceiling, window pane, rug plane) may be planes/boxes **with PBR textures**.
- Assets: only CC0 / CC-BY; every asset gets a line in `CREDITS.md` (name, author, source URL, license).
- No Kenney/Quaternius-style low-poly assets (spec §8.2).
- First meaningful render after ≤ ~10 MB of downloads: load 1k-resolution assets first; 2k textures only on quality `high`, loaded after first render.
- Desktop + phone: phone defaults to quality `medium`; target ≥ 30 FPS on medium.
- No synthesized audio. (Audio is out of scope for this milestone.)
- Old code is not copied. Old `public/assets/*.jpg` textures may be reused.

## Review Focus

1. **Avatar walks into furniture or through walls** at any speed or framerate (big `dt` after tab switch) → must stop at colliders; test `step clamps dt and never ends inside a collider` (Task 4).
2. **Phone user** (touch only, portrait or landscape) → joystick works, sit button reachable, no keyboard needed; test `joystick maps drag to normalized vector with deadzone` (Task 5) + Playwright mobile viewport smoke (Task 9).
3. **An asset fails to download/parse** → scene still renders, a console warning names the asset, loading screen finishes; test `loadAll resolves with missing entries when one asset 404s` (Task 2).
4. **Two seats overlap / pressing Sit far from any seat** → nearest seat within 1.2 m only, nothing otherwise; test `nearestSeat returns null beyond radius and picks closest` (Task 6).
5. **Cat walks through furniture or the avatar, or gets stuck** → cat only moves between predefined spots along clear paths and re-plans when the avatar blocks its target; test `cat picks a new target when blocked` (Task 7).
